# Smile Segment Labeler 使用マニュアル

本ツールは、動画とSmileRankデータ（CSV）を同期させ、笑顔の区間（セグメント）を微調整・ラベリングするためのブラウザベースのアプリケーションです。

## ラベルの定義について

作業を開始する前に、以下のラベル定義（特に `Mixed Smile` と `False Smile` のニュアンス）を必ず確認してください。

### 1. True Smile (真の笑顔)

* 心からの喜びや楽しさに起因する、自然な笑顔です。

### 2. Mixed Smile (複合的・曖昧な笑顔)

* **定義**: 以下のいずれかに該当する笑顔を指します。
  * **複合的要因**: 複数の要因が混在している場合（例：時間経過とともに「作り笑い」から「真顔」へ変化する、あるいは同時に複数の感情が混ざっている）。
  * **判断困難**: 明確に分類することが難しい、曖昧な状態の笑顔。

### 3. False Smile (その他の笑顔)

* **注意**: UI上では便宜的に「False Smile」と表記されていますが、単なる「偽の笑顔」という意味ではありません。
* **定義**: `True Smile` 以外の笑顔のうち、「発生要因が単一であり、かつアノテーター（作業者）の視点からその理由が説明可能である」もの。
  * 例：写真撮影のための意図的な笑顔、社会的マナーとしての愛想笑いなど、要因がはっきりしているもの。

## 1. データのインポート（準備）

画面上部の「Input」エリアで、以下の順序でファイルを読み込んでください。

1. **Video File**:
   * 分析対象の動画ファイル（.mp4など）を選択します。
2. **CSV Folder**:
   * SmileRankデータが含まれる**フォルダ**を選択します。
   * フォルダ内には `smile_data_segment_XX.csv` という連番ファイルが含まれている必要があります。
   * ツールはこれらを自動的に結合し、グラフを描画します。
3. **DAT File**:
   * Pythonスクリプト等で生成された初期の区間データファイル（`.dat`）を選択します。
   * これをベースに修正作業を行います。
4. **FPS**:
   * 動画のフレームレートを入力します（デフォルトは30）。

## 2. 画面の見方

* **左側エリア**:

  * **動画プレーヤー**: 現在のフレームを表示します。倍速再生（0.5x / 1.0x）の切り替えが可能です。
  * **波形グラフ (Plot)**:
    * **青線**: Smile Rank（数値が低いほど笑顔が強い）。
    * **赤点線**: Long Gap（データの欠損区間）。
    * **縦の点線**: 現在の動画フレーム位置。
    * グラフをクリックすると、そのフレームへ瞬時にジャンプします。
    * グラフの縦軸は 0〜10 に固定されています。
* **右側エリア**:

  * 操作パネルです。ナビゲーション、区間調整、ラベリング、書き出しを行います。

## 3. 基本的なワークフロー

### A. ナビゲーション（移動）

* **Prev Seg / Next Seg**: 前後の区間へ移動します。
* **Next Unlabeled**: まだラベル付けされていない次の区間へ自動ジャンプします。効率的な作業のためにこのボタンを活用してください。

### B. 区間の調整（新規作成・修正）

既存の区間がズレていたり、検出漏れがあったりする場合に使用します。

* **区間の新規作成**:

  * **`+ New Seg` ボタン**: 現在の再生位置を起点として、60フレーム（約2秒）の新しい区間を作成します。作成後、自動的にその区間が選択されます。
* **開始・終了位置の修正**:

  * **`📍Set` ボタン**:
    * Start横の `Set`: 現在の動画フレームを、この区間の「開始点」に設定します。
    * End横の `Set`: 現在の動画フレームを、この区間の「終了点」に設定します。
  * **手動入力**: 数値ボックスにフレーム番号を直接入力し、`Apply Frame Changes` を押すことでも修正可能です。

### C. ラベリングと備考

現在の区間に対して評価を行います。

1. **ラベルボタン**: 以下のいずれかをクリックして分類します。
   * `True Smile` (緑)
   * `Mixed Smile` (黄)
   * `False Smile` (赤) ※定義に注意
   * `Discard` (灰): 笑顔ではない、または分析対象外として捨てる場合。
2. **Remark (備考)**:
   * 判断の根拠やメモがあれば入力してください（日本語入力可）。
   * 入力内容は自動的に保存され、エクスポート時に出力されます。

### D. 保存と再開

* **自動保存 (キャッシュ)**:
  * 作業内容はブラウザのキャッシュ（LocalStorage）に自動保存されます。ブラウザを誤って閉じても、再度同じDATファイルを読み込めば作業を続きから再開できます。
* **Clear Cache**:
  * 最初からやり直したい場合は、このボタンでキャッシュをクリアしてください。

### E. 書き出し (Export)

* **Export DAT**:
  * 作業が完了したらクリックしてください。
  * `start_frame end_frame label remark` の形式でファイルがダウンロードされます。
  * ※ `Unlabeled` や `Discarded` の区間は出力ファイルには含まれません。

---

## 4. ショートカット・ヒント

* **波形活用**: 動画だけでなく、下の波形グラフを見て「値が下がっている（笑顔が強い）区間」をクリックし、そこから `📍Set` で範囲を決めるとスムーズです。
* **倍速再生**: 微妙な表情変化を確認したいときは `0.5x`、大まかに確認したいときは `1.0x` を使い分けてください。
